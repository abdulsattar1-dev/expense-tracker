# 💰 Expense Tracker

Track your daily spending. Add expenses, see the total in rupees, and delete what you don't need. Your data stays saved after you refresh the page.

**🔗 Live demo:** _add your Vercel link here_

## ✨ Features
- Add an expense with a name and amount (Rs)
- Total amount updates automatically
- Delete any expense
- **Data is saved in the browser (localStorage)** — it stays after refresh
- Empty boxes are not accepted

## 🧠 What I learned
- Controlled forms with `onSubmit` and `preventDefault()`
- Adding up numbers with `reduce()`
- Saving and loading data with `localStorage`
- `useEffect` to save every time the list changes
- Unique IDs with `Date.now()`

## 🛠️ Run it on your computer
```bash
git clone https://github.com/abdulsattarnangri7-desktoop/expense-tracker.git
cd expense-tracker
npm install
npm run dev
```
Then open http://localhost:5173
